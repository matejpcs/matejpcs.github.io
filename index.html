FROM DOWNLOAD TO FIRST CONNECTION

Two sides.
One connected world.

Netflared uses a server plugin to publish a Cloudflare Tunnel and a client mod to connect players through Cloudflare Access. Install the matching pieces for your setup.

GUIDE 01 / CLIENT

Set up the player client

The client mod starts cloudflared access tcp when you choose Connect, then joins through a local port.

Client project README ↗

Install and configure

  1. Match your Minecraft version and loader. Pick the client build above that fits your instance. The base matejpcs/netflared project is Fabric for Minecraft 26.2; its README lists Fabric Loader 0.19.0 or newer, Fabric API 0.160.0+26.2 or later, and Java 25. NeoForge and Forge variants may have different requirements, so check the chosen project README.
  2. Install the mod files. Put the Netflared client JAR and its required loader API in the instance’s mods/ folder. For the vanilla launcher, the usual Windows path is %appdata%\.minecraft\mods; Prism, MultiMC, and ATLauncher use the selected instance’s Minecraft mods/ folder.
  3. Open multiplayer settings. Launch Minecraft, open Multiplayer, then select the Netflared button near the top-left of the server list.
  4. Add a tunnel profile. Enter a display name, the hostname provided by the server administrator (for example play.example.com), and the local port (usually 25565). Choose Save & Sync.
  5. Connect and join. Select Connect beside the profile. On first connection Netflared downloads the official cloudflared executable, opens the Access TCP connection, and shows its status. When it says connected, choose Join. You can instead connect manually to localhost:<port>.

Profiles and files

Create more than one profile for different servers. Each profile stores its own hostname and port; more than one tunnel can run at once.

Configuration and the downloaded binary live under .minecraft/config/netflared/. The profile data is in netflared.json; the executable is in bin/.

Connection tips

The server owner must provide a working Cloudflare Access TCP hostname. If the connection reports a bad handshake, the server-side ingress must use TCP and have WebSockets enabled.

GUIDE 02 / SERVER

Set up Netflared Server

Use the same Cloudflare setup flow for every server loader. The server plugin creates and runs the tunnel; players connect with a companion Netflared client mod.

Server project README ↗

What you need

  • Java 25 and a Minecraft server version supported by the selected build. The Paper edition in matejpcs/netflared-server targets Paper 26.2.
  • A Cloudflare account and an active domain/zone in Cloudflare DNS.
  • Outbound internet access, including HTTPS to api.cloudflare.com, GitHub release downloads, and Cloudflare Tunnel connectivity.
  • No inbound Minecraft port forwarding is needed. Netflared routes TCP ingress to the server’s configured game port.

Install the plugin

  1. Download the Paper 26.2 build from the Netflared Server Paper card above.
  2. Stop the Minecraft server and install the JAR in its loader’s plugin or mod folder (for example, plugins/ on Paper or mods/ on Fabric, NeoForge, and Forge). Start the server and confirm Netflared loads.
  3. Create a scoped Cloudflare API token as described below, then run /netflared setup <cloudflare-api-token> from the console or as an administrator.
  4. Choose a listed Cloudflare zone with /netflared setup select <number>. The default hostname begins with play. You can choose another name such as mc or a nested name such as survival.play.
  5. Netflared creates the remotely-managed tunnel, configures TCP ingress to localhost:<Paper port>, creates or updates the hostname’s CNAME, downloads the platform-matched cloudflared, saves its tunnel configuration, and starts the connector.
  6. Give players the resulting hostname and have them install the matching Netflared client edition. The server plugin alone does not make an unmodified Minecraft client connect directly to a Cloudflare TCP hostname.

Cloudflare token permissions

Create a custom API token with only these permissions:

  • Account: Cloudflare Tunnel (Edit)
  • Zone: DNS (Edit)
  • Zone: Zone (Read)

Restrict the account resource to the account that owns the tunnel and the zone resource to the Minecraft domain. The API token is used for setup and is not saved by the plugin.

Protect your server config

The persistent tunnel token is stored in the Netflared server data folder so the connector can restart. On Paper, that is plugins/Netflared/config.json. Treat the file like a password: restrict access and never publish or commit it.

The setup command accepts the API token as an argument, so a host console or command history may retain it. Use the server console privately.

Manage the tunnel in game or console

/netflared statusShow hostname, port, tunnel ID, and connector state/netflared infoShow selected zone, platform, and local binary path/netflared connectDownload if needed and start cloudflared/netflared disconnectStop the connector/netflared reloadReload config and restart the connector if configured/netflared resetRemove local config and stop cloudflared; remote tunnel and DNS are kept
The shared server guide applies to Paper, NeoForge, Fabric, and Forge editions. matejpcs/netflared-server is listed above as Netflared Server Paper and documents the Paper 26.2 edition.
